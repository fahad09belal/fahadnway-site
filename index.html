PhalqonOS "Origin"

11.11.2023

PhalqonOS: Semantic Block Encoding System

PhalqonOS is a lightweight, terminal-based operating environment built entirely in Bash, designed around a custom Semantic Block (SB) cipher. It features a live cryptographic menu that translates standard text into a unique symbolic code and decodes it back into readable English using automated associative arrays.

Originally developed in November 2023 completely from scratch within an Android Termux environment, it represents a self-taught developer's first foray into programming and technology.

Born out of curiosity, this project served as an experimental sandbox for learning scripting, system architecture, and computational logic.

PhalqonOS became a stepping stone toward later software architectures such as F.A.H.A.D and Project !Froyo¡.

PROJECT HIGHLIGHTS
  • Live SB Encoding & Decoding: Two-way translation using Bash associative arrays to process custom symbolic mappings.
  • Universal Deployment: Designed for compatible Linux, macOS, Windows Bash environments, and mobile terminal emulators.
  • Historical Origin Point: The project represents an early milestone in the creator's programming journey.
HOW TO USE PHALQONOS

PhalqonOS is a terminal-based Semantic Block Encoding OS developed by Fahad Al-Belal. Because it runs as a Bash script, it can be used on systems providing a compatible terminal environment.

01 · LINUX & macOS — NATIVE TERMINAL

Both Linux and macOS provide terminal environments capable of running Bash.

Step 1

Open your Terminal.

Step 2

Create a dedicated directory and open a new file: 

mkdir -p $HOME/phalqonos && cd $HOME/phalqonos && nano phalqon.sh

Step 3

Paste the full PhalqonOS Bash script into the editor.

Step 4

Save and exit Nano: CTRL + O, Enter, then CTRL + X.

Step 5

chmod +x phalqon.sh
echo "alias phalqon='$HOME/phalqonos/phalqon.sh'" >> ~/.bashrc
source ~/.bashrc

On macOS, you may need to use ~/.zshrc instead.

Step 6

phalqon
02 · WINDOWS — GIT BASH / WSL

Option A — Git Bash

Install Git for Windows, open Git Bash, then follow the Linux/macOS commands.

Option B — WSL

Open PowerShell as Administrator: 

wsl --install

Restart the computer, open the installed Linux distribution, and follow the Linux/macOS installation steps.

03 · ANDROID — TERMUX

Step 1

Install Termux from a supported distribution such as F-Droid or the official Termux project repository.

Step 2

pkg update && pkg upgrade

Step 3

pkg install nano

Step 4

mkdir -p $HOME/phalqonos && cd $HOME/phalqonos && nano phalqon.sh

Step 5

Paste the PhalqonOS script into Termux, save it, and exit Nano.

Step 6

chmod +x phalqon.sh
./phalqon.sh
04 · USING PHALQONOS
  1. Encode Sentence — Convert standard English text into Semantic Block code.
  2. Decode SB Code — Convert SB code back into English.
  3. About — View system philosophy and credits.
  4. Log-out — Exit the OS environment.
