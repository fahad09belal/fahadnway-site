F.A.H.A.D
PROJECT 01

F.A.H.A.D stands for FAST ASYMMETRIC HASH-BASED ALGORITHM FOR DECRYPTION. It is a Semantic Block (SB) encoding system created by Fahad Al-Belal. The project converts raw letters and sentences into static cryptographic symbols through a fixed matrix mapping system.

Version 01 — First Encoder
Version 01
07 DEC 2025

The earliest version of F.A.H.A.D. This was the beginning of the encoder system. It had no sounds, enhanced UI or additional encryption layers. The mapping was visible and login was required.

!Froyo¡ NES
PROJECT 02

A Nintendo Entertainment System emulator project built during the development journey of !Froyo¡. The project progressed from a beginner Kotlin implementation into a C/C++ rewritten emulator with significantly deeper hardware-level work.

Version 01 — Kotlin
Version 01
16 MAR 2026

A beginner Kotlin implementation and an important learning milestone. The emulator had a basic UI, but performance was laggy, choppy and generally unplayable.

Open Version
Version 02 — Final C/C++ Rewrite
Version 02 Final
24 APR 2026

A complete rewrite using C/C++. CPU, PPU and APU processing was optimized and deeper manual configuration was introduced.

Technical Features

Pixel-perfect graphics, Jetpack Compose Canvas, reusable offscreen bitmaps, nearest-neighbor scaling, MMC3/MMC5 scanline IRQ, cycle-accurate CPU checks, MMC5 math multiplier, MMC5 audio, ExRAM and ExGrafix.

PhalqonOS Origin
PROJECT 06

The original PhalqonOS environment created on 11 November 2023. A Bash terminal-based operating environment built around a custom Semantic Block cipher.

Origin — 11 Nov 2023
PhalqonOS Origin
11 NOV 2023

The historical origin of PhalqonOS and one of the earliest programming milestones. It used Bash associative arrays to implement live Semantic Block encoding and decoding.

The project was designed for universal deployment across Linux, macOS and Windows WSL, as well as mobile terminal environments.

Origin

This project represents the beginning of the Semantic Block architecture that later influenced F.A.H.A.D and other projects.
